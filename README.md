# Tec_Team

> A modern tech team app / project starter — things to do when _... in different mood ;)

---

## 🧠 About

**Tec_Team** is a collaborative project template built with TypeScript and modern web technologies. It provides a base structure for building full-stack applications with clear separation of client, server, and shared modules.
This README will help developers set up, understand, and contribute to the project easily.

---

## 🚀 Features

* 📦 Modular project structure
* 💡 TypeScript everywhere (client, server, shared)
* ⚡ Fast development with Vite / Node.js
* 🛠 Ready for extension and customization
* 📚 Good starting layer for team projects and demos

---

## 🧱 Tech Stack

**Frontend**

* Vite
* TypeScript
* CSS

**Backend**

* Node.js (TypeScript)

**Shared**

* Shared TypeScript types and utilities

Tools & Config:

* ESLint + Prettier (optional)
* Drizzle ORM (seen from config file)
* Vite plugin ecosystem

---

## 📁 Project Structure

```
Tec_Team/
├── client/              # Frontend app (Vite + TypeScript)
├── server/              # Backend API / server logic
├── shared/              # Shared types, utilities
├── .gitignore
├── package.json
├── tsconfig.json
├── drizzle.config.ts    # Database/ORM config
├── vite.config.ts       # Vite config
└── README.md
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Kool-Aayush/Tec_Team.git
```

Navigate into the project:

```bash
cd Tec_Team
```

Install dependencies:

```bash
npm install
```

---

## ▶ Development

Start the development environment:

```bash
npm run dev
```

> This should start the frontend and backend (if configured) with fast live reloads.
